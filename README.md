# Terminal Portfolio

An interactive terminal-inspired portfolio built with TypeScript, Web Components, Express, and OpenAI.

The application presents portfolio information through a command-driven interface, including project exploration, experience summaries, GitHub repository integration, theme customization, and an AI-powered "Machine Spirit" assistant.

## Features

* Terminal-style user interface
* Custom Web Components
* GitHub repository integration
* Multiple visual themes
* AI-powered Machine Spirit assistant
* Express backend API
* OpenAI Responses API integration

## Tech Stack

### Frontend

* TypeScript
* Vite
* Web Components

### Backend

* Node.js
* Express
* OpenAI API

## Development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```

Start the production build:

```bash
npm run start
```
